## Производная по направлению

$$
\begin{align*}
&\frac{ \partial f }{ \partial l } (a)=\lim\limits_{ t \to 0} \frac{f(a_{1}+t\cos \alpha_{1},\dots,a_{m}+t\cos\alpha_{m})-f(a)}{t} \\
&\frac{ \partial f }{ \partial l } (a)=\frac{ \partial f }{ \partial x_{1} } (a)\cos\alpha_{1}+\dots+\frac{ \partial f }{ \partial x_{m} } (a)\cos\alpha_{m}
\end{align*}
$$

## Градиент

$$
\begin{align*}
&\mathrm{grad}\ f(a)=\left( \frac{ \partial f }{ \partial x_{1} } (a) ,\dots, \frac{ \partial f }{ \partial x_{m} } (a)\right)  \\
&\frac{ \partial f }{ \partial l } (a)=(\mathrm{grad}\ f(a),\vec{n})
\end{align*}
$$
### Характеризует направление и величину максимального роста производной по направлению в точке

$$
\frac{ \partial f }{ \partial l } (a)=|\mathrm{grad}\ f(a)||\vec{n}|\cos \varphi =|\mathrm{grad}\ f(a)|\cos \varphi 
$$
имеет наибольшее значение при $\cos \varphi=1$ *(совпадает направление $\vec{n}$ и градиента*)
